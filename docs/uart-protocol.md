# UART Protocol (STM32 Tag → ESP32-S3)

## 물리 계층

- **단방향**: Tag가 일방적으로 송신, ESP32는 수신만
- **보드레이트**: `115200`, 8 data bits, no parity, 1 stop bit
- **라인 종결**: `\n` (LF). `\r\n` 도 ESP32 측 `trim()` 으로 흡수

## 패킷 포맷

한 줄 텍스트, ASCII:

```
Anchor: 0xAABB, Distance: 1.23m
```

| 필드 | 형식 | 설명 |
|------|------|------|
| `Anchor:` | 고정 헤더 | |
| 16-bit ID | `0x` + 4자리 hex | anchor 식별자 |
| `,` | 구분자 | |
| `Distance:` | 고정 헤더 | |
| 실수 | 소수점 둘째 자리 권장 | 미터 단위 |
| `m` | 단위 마커 | ESP32에서 종결자로 사용 |

## 송신 주기

- Tag는 anchor 4개의 거리를 **각각 한 줄씩** 순차 송신
- 한 사이클(4줄) 송신 후 다음 사이클까지 ≥ 50ms 권장 (1Hz 위치 계산 보장)

## 거리 유효성 (ESP32 측 가드)

- `0 < distance < 50m` 외 값은 폐기
- 음수, NaN, `inf` 수신 시 폐기 후 다음 패킷 대기
- 알 수 없는 anchor ID 수신 시 무시 (테이블에 없으면 버림)

## 향후 확장 (Known Gap)

- **바이너리 패킷**(예: COBS+CRC16) — 텍스트 파싱 비용·타임아웃 줄이려면
- **양방향 채널** — 현재 단방향. ESP32 → Tag로 캘리브레이션 명령 보내려면 양쪽 재설계 필요
- **타임스탬프** — anchor별 거리 동시성 보장하려면 송신 측 timestamp 추가 검토
