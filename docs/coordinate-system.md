# Coordinate System

## 단위

- 길이: 미터(m), 소수점 둘째 자리까지

## 2D (현재)

- **원점 (0, 0)**: Anchor 1번이 설치된 위치
- **X축 양의 방향**: Anchor 1번 → Anchor 2번 (수평, 오른쪽이 양수)
- **Y축 양의 방향**: 오른손 좌표계 — X축에서 반시계로 90° (앞쪽 또는 위쪽이 양수)
- 모든 좌표는 **바닥 평면 투영** 기준 (z = 0 가정)

## 3D 확장 시 가정 (Known Gap)

- **Z축 양의 방향**: 천장 쪽이 양수 (오른손 좌표계 유지)
- **Anchor 배치 제약**: 4개 모두 같은 평면(예: 천장)에 있으면 Z 추정 불가능
  - 천장 2개 + 바닥 2개, 또는 anchor 5~6개로 확장 권장
- **수식 변경**: 거리방정식이 3변수가 되므로 Least Squares가 더 강력하게 필요

## 좌표 갱신 절차

1. 줄자/레이저 거리계로 anchor 위치 측정
2. [hardware-layout.md](hardware-layout.md) 의 Anchor 좌표 표 갱신
3. 코드의 하드코딩 좌표 → 매크로(`#define`) 또는 NVS 저장으로 이전 검토
4. 검증: 알려진 위치에 tag 두고 측위 오차 확인 (Sprint Contract 기준 ≤ 15cm)
